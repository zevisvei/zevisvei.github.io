מדיניות פרטיות — yemot-suite

yemot-suite הוא שרת פרטי שמחבר קווי ימות המשיח לשירותים של בעל הקו.

כשבעל הקו מתחבר עם Google, השרת מקבל גישה רק למה שאישר: הדואר (קריאה ושליחה מהטלפון), אנשי הקשר, היומן והמשימות שלו. הנתונים משמשים רק להפעלת השירותים האלה עבורו, לא נמכרים, לא מועברים לצד שלישי ולא משמשים לפרסום.

השימוש בנתונים שמתקבלים מ-Google API עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

אפשר לבטל את הגישה בכל רגע: בכפתור הניתוק בממשק, או ב- myaccount.google.com/permissions. עם הניתוק, ההרשאה נמחקת מהשרת.
